# Note Trainer Docs

This folder is the handoff area for future work on the piano note trainer.

## Files

- `checkpoint-2026-05-29.md`: current implementation checkpoint, user decisions, verification notes, and follow-up ideas.

## Current Direction

The trainer now has the original two-octave note-name exercises, a full-piano `Name + group` exercise, a `Steps` interval quiz, `Read notes` staff-note practice, and a lightweight `Solfege` launcher for the local Gradio/Whisper tool. Future agents should read the checkpoint before changing notation behavior, because Scientific, Helmholtz, and Mixed notation rules are intentionally mapped together.
